Stay up to date with new features, improvements, and bug fixes shipped in Record.

<Update label="02/11/2026">
  ## More languages and coding options

  _v0.6.3_

  **Platform**

  - Verifications submit automatically if a candidate goes idle for 10 minutes, so results are never lost halfway.
  - Job mandate analytics are now visible in the Playground.
  - Campaign setup has clearer fields and layout.
  - Call results show directly on the result page alongside the rest of the verification.
  - A public status page is live at [status.userecord.io](https://status.userecord.io), so you can check if Record is running normally.

  **White Collar**

  - Candidates can write code in several programming languages during an assessment.

  **Blue/Grey Collar**

  - The candidate app now supports Bengali and Marathi.
</Update>

<Update label="26/10/2026">
  ## White collar API and duplicate control

  _v0.6.2_

  **Platform**

  - White collar verifications can now be created and managed over the API, in the same way as blue collar.
  - The same candidate cannot be added twice under one job mandate, so your credits are not spent on repeat verifications.
  - Candidate location now captures the pincode, which makes local shortlisting easier.
  - The campaign page has clearer analytics and a cleaner layout.
  - Staying signed in for 7 days, and a fix for being logged out on page reload.
  - Verifications fall back to another channel when the first one fails, so fewer candidates drop out.
  - Faster and more accurate question generation and scoring.
</Update>

<Update label="19/10/2026">
  ## Result page and call analytics

  _v0.6.1_

  **Platform**

  - The result page has a cleaner layout, with easier movement between a candidate's result and the logs.
  - Job mandate stats now include follow-up call numbers, so you can see how many candidates were chased and what came back.
  - Interest collection answers show the full transcript on the result page, not just the summary.
  - A verification link locks once the candidate finishes on any channel, so the same candidate cannot be counted twice across WhatsApp, SMS and calls.
  - Fixed credits display and switching between organisations in the Playground.
  - Spoken answers are transcribed with an updated model, so regional languages come through more accurately.
</Update>

<Update label="13/10/2026">
  ## Job mandate controls and candidate experience

  _v0.6.0_

  **Platform**

  - Job mandates accept a minimum and maximum experience in years, so you can ask for ranges like 3 to 30 instead of picking a fixed band.
  - Job mandates can be set for roles abroad, with the country chosen from a search.
  - Workflow schedules can start and end on the half hour, so calls can run from 6:30 PM to 8:30 PM instead of a full hour block.
  - Verification reports now show enrichment and interest answers even when scenario questions are switched off, so no response is lost.
  - Verification links sent on WhatsApp, SMS and email are now short links, which are easier to open on a phone and look more trustworthy to candidates.
  - Documentation for the blue/grey collar API and SDK is now live.

  **Blue/Grey Collar**

  - Candidates are prompted to turn up their volume before the first question, so they do not miss what is being asked.
  - Candidates who are not interested in a role can say so, confirm, and give a reason. The call then moves on to what else they are open to, across every verification type.
</Update>

<Update label="05/10/2026">
  ## Blue collar over the API

  _v0.5.3_

  **Platform**

  - Hiring teams can filter candidates by language, verdict and message status, and narrow workflows by job description and campaign.
  - Any list in the Playground can be exported to Excel, with filters carried over.
  - Verification reports show what else a candidate is open to, instead of a plain verified badge, so you can place them against other roles.
  - Candidate messages go out under your own organisation name and SMS templates.
  - Enrichment questions are capped at a sensible length, so candidates stay with the flow to the end.
  - Scenario questions can be regenerated until the right one comes up.
  - Phone numbers in Indian format work whether uploaded in bulk or typed in.

  **Blue/Grey Collar**

  - Everything can now run through the API: creating workflows and job mandates, launching campaigns and pulling analytics. No need to open the Playground.
  - Recruiters can send a verification straight from a campaign, choosing the skills and details to collect.
  - Customers can start a verification experience from the website with just their mobile number.
  - Voice calls feel closer to a real conversation, with shorter pauses and quicker replies.
  - Candidates answer two questions about their interests instead of four, so more of them finish the call.
  - Spoken answers are scored more accurately.
  - Candidates can retake a video answer without losing their earlier responses.
</Update>
