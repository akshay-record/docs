Stay up to date with new features, improvements, and bug fixes shipped in Record.

<Update label="06/15/2026" description="">
  ## Smarter blue collar questions

  - Blue collar verifications use AI to create fresh questions.
  - Skills are listed separately for white collar and blue/grey collar roles.
</Update>

<Update label="06/07/2026" tags="v1.0" description="v1.0">
  ## Custom programming verification and test mode

  - AI programming verifications accept your own inputs during setup.
  - Test mode has usage limits, so Record can be tried safely before going live.
  - Fixed issues in the verification popup.
</Update>

<Update label="06/01/2026" description="v1.0">
  ## Voice verification and setup controls

  - Blue/grey collar candidates can be verified through AI voice calls.
  - Verification settings lock once setup is complete, in both the API and the Playground.
  - Skills can be searched while setting up a verification.
  - Fixed issues in score cards, verification setup and blue collar verifications.
</Update>
