---
title: "List All Assignments"
api: "GET /api/v1/assessments/assignments"
description: "List assignment batches across an organization."
---

## Overview

Returns all assignment batches across the organization, filtered by mode.

Use `mode=test` for test-mode assessment assignments and `mode=live` for live-mode assessment assignments.

---

## Query Parameters

<ParamField query="orgId" type="string" required>
  Organization identifier.
</ParamField>

<ParamField query="mode" type="string" required>
  Assignment mode. Must be `test` or `live`.
</ParamField>

---

## Response Fields

<ResponseField name="success" type="boolean">
  `true` when the request succeeds.
</ResponseField>

<ResponseField name="data" type="array">
  Assignment batches across the organization.

  <Expandable title="Assignment fields">
    <ResponseField name="assignmentId" type="string">
      Unique assignment batch ID.
    </ResponseField>
    <ResponseField name="assessmentId" type="string">
      Assessment identifier.
    </ResponseField>
    <ResponseField name="batchName" type="string">
      Batch label.
    </ResponseField>
    <ResponseField name="totalCandidates" type="number">
      Number of candidates in the batch.
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

---
