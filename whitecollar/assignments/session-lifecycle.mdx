## Overview

Once assigned, each candidate has a session that moves through these statuses.

| Status | Trigger | Description |
| --- | --- | --- |
| `registered` | Assignment created | Candidate added and session token issued. |
| `verified` | Identity check passed | Candidate completed face or ID verification. |
| `in_progress` | Assessment started | Candidate is answering questions. |
| `submitted` | Candidate submits | Answers are submitted and scoring starts. |
| `timed_out` | Duration limit reached | Session is auto-submitted. |
| `disqualified` | Proctoring violation | Critical violation detected and session locked. |
