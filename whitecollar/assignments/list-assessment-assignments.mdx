---
title: "List Assessment Assignments"
api: "GET /api/v1/assessments/{assessmentId}/assignments"
description: "List assignment batches for one assessment."
---

## Overview

Returns all batches for a specific assessment.

<Note>
  Use this endpoint when you need assignment batches for one assessment only.
</Note>

---

## Path Parameters

<ParamField path="assessmentId" type="string" required>
  Assessment identifier.
</ParamField>

---

## Query Parameters

<ParamField query="orgId" type="string" required>
  Organization identifier.
</ParamField>

---

## Response Fields

<ResponseField name="success" type="boolean">
  `true` when the request succeeds.
</ResponseField>

<ResponseField name="data" type="array">
  Assignment batches.

  <Expandable title="Assignment fields">
    <ResponseField name="assignmentId" type="string">
      Unique assignment batch ID.
    </ResponseField>
    <ResponseField name="batchName" type="string">
      Batch label.
    </ResponseField>
    <ResponseField name="totalCandidates" type="number">
      Number of candidates in the batch.
    </ResponseField>
    <ResponseField name="duplicatesRemoved" type="number">
      Number of duplicates skipped.
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

---
