title: "Overview Dashboard"

description: "Retrieve dashboard metrics for assessments and sessions."
---

## Overview

The overview endpoint aggregates assessment and session data into dashboard-ready metrics filtered by mode.

<Note>
  Use this endpoint for overview cards, assessment funnels, and mode-level analytics.
</Note>

---

## Query Parameters

<ParamField query="orgId" type="string" required>
  Organization identifier.
</ParamField>

<ParamField query="mode" type="string" required>
  Dashboard mode. Must be `test` or `live`.
</ParamField>

---

## Response Fields

<ResponseField name="stats" type="object">
  <Expandable title="Stats fields">
    <ResponseField name="totalAssessments" type="number">
      Number of assessments.
    </ResponseField>
    <ResponseField name="assignedCandidates" type="number">
      Total assigned candidates.
    </ResponseField>
    <ResponseField name="completedAttempts" type="number">
      Completed attempts.
    </ResponseField>
    <ResponseField name="averagePassRate" type="number">
      Passed sessions divided by completed sessions, multiplied by 100.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="funnel" type="object">
  <Expandable title="Funnel fields">
    <ResponseField name="created" type="number">
      Created assessment count.
    </ResponseField>
    <ResponseField name="assigned" type="number">
      Assigned candidate count.
    </ResponseField>
    <ResponseField name="started" type="number">
      Started session count.
    </ResponseField>
    <ResponseField name="completed" type="number">
      Completed session count.
    </ResponseField>
    <ResponseField name="passed" type="number">
      Passed session count.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="modeStats" type="array">
  Metrics grouped by assessment mode.
</ResponseField>

---

| Metric | Calculation |
| --- | --- |
| `averagePassRate` | Passed sessions divided by completed sessions, multiplied by 100. |
| Funnel percentage | Stage count divided by assigned count, multiplied by 100. |
| `passRate` | Passed sessions for that mode divided by completed sessions, multiplied by 100. |
| `avgScore` | Average candidate score across completed sessions. |
