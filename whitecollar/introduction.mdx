The AI Assessment Portal allows organisations to create AI-generated assessments tailored to a specific job role and skill set, review questions, and send assessments to candidates via email.

- Create AI-generated assessments tailored to job role and skill set
- Configure question types and mark allocation (always totalling 100)
- Review and edit AI-generated questions before sending
- Send assessments to candidates via AWS SES email
- Save and reuse configurations for future candidates
- Candidate takes the test with proctoring, recording, and code execution

| Application | Purpose | Repo |
|---|---|---|
| white-collar-assessment-portal-backend | Creator API (session, assessment, config) | white-collar-assessment-portal-backend |
| white-collar-assessment-portal | Creator modal UI (Next.js, iframe) | white-collar-assessment-portal |
| record-assessment-backend | Candidate test API (exam, proctoring, scoring) | record-assessment-backend |
| record-assessment-frontend | Candidate test UI (Next.js) | record-assessment-frontend |
