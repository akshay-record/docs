---
title: "API Key Management"
description: "API key fields for authenticating with the WhiteCollar Assessment Portal."
---

| Field | Description |
|---|---|
| `keyId` | Unique key identifier (key_xxxx) |
| `apiKey` | Public key (wc_xxxx) sent in headers |
| `secretKey` | Secret for HMAC / direct verification |
| `orgId` | Organisation this key belongs to |
| `userId` | User who created the key |
| `mode` | test or live |
| `isActive` | Whether the key is currently active |
