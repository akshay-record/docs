title: "Webhook Integration"
description: "Receive real-time notifications when a candidate completes an assessment."
---

Webhooks allow the parent application to receive real-time notifications when a candidate completes an assessment. The event is delivered as a signed HTTP POST to the URL registered by the organisation.

## Webhook trigger events

| Event | When it fires |
|---|---|
| assessment.submitted | Candidate submits the exam (score calculated) |
| assessment.timed_out | Session expires before candidate submits |
| assessment.disqualified | Critical proctoring violation threshold exceeded |

## Webhook payload

```
POST <your-webhook-url>
Content-Type: application/json
x-webhook-signature: HMAC-SHA256(secretKey, payload)
x-webhook-timestamp: <Unix ms>
```

## Verifying the webhook signature

Always verify the signature before processing. Replay attacks are prevented by the timestamp window (5 min in production).

```js
// Node.js verification example
const crypto = require('crypto');
function verifyWebhook(body, signature, timestamp, secretKey) {
  const timeDiff = Math.abs(Date.now() - parseInt(timestamp));
  if (timeDiff > 5 * 60 * 1000) throw new Error('Timestamp expired');
  const payload = JSON.stringify(body, Object.keys(body).sort());
  const expected = crypto
    .createHmac('sha256', secretKey)
    .update(`POST:${timestamp}:${payload}`)
    .digest('hex');
  if (!crypto.timingSafeEqual(
    Buffer.from(signature, 'hex'),
    Buffer.from(expected, 'hex')
  )) throw new Error('Invalid signature');
}
```

## Webhook delivery guarantees

- At-least-once delivery — your endpoint should be idempotent (use webhookEventId)
- Retries on 5xx or timeout (3 attempts with exponential backoff)
- Delivery timeout: 10 seconds per attempt
- Failed events stored in whitecollar_records with status=failed for manual replay

## Responding to webhooks

Return HTTP 200 within 10 seconds to acknowledge. Any non-2xx response or timeout triggers a retry. Do heavy processing asynchronously after acknowledging.

```js
// Express.js example
app.post('/webhook/assessment', express.json(), (req, res) => {
  verifyWebhook(req.body, req.headers['x-webhook-signature'],
    req.headers['x-webhook-timestamp'], process.env.WEBHOOK_SECRET);
  res.status(200).json({ received: true }); // acknowledge first
  // process asynchronously
  processAssessmentResult(req.body).catch(console.error);
});
```

## Test mode vs Live mode

| Mode | Behaviour |
|---|---|
| test | Webhooks delivered but flagged with mode=test. No production data affected. |
| live | Full production delivery. Failures retried. Events persisted. |
