## Overview

Custom assessments are built through a 4-step wizard. `NON-IT` roles use 3 steps because Skill Assessment is skipped.

| Step | Name | Description | NON-IT |
| --- | --- | --- | --- |
| 1 | Assessment Details | Job title, role type, marks, duration, difficulty, and skills. | Included |
| 2 | Knowledge Assessment | Add sections and questions. | Included |
| 3 | Skill Assessment | Add coding problems with test cases and reference solutions. | Skipped |
| 4 | Review & Publish | Review the full assessment, validate marks, and publish. | Included |
