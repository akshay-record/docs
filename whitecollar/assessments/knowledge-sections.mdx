## Overview

Knowledge sections contain questions for non-coding assessment content.

| Section type | Description | Answer requirement |
| --- | --- | --- |
| `single_choice` | Multiple choice with one correct answer. | Mark exactly one answer with `isCorrect: true`. |
| `true_false` | Binary true or false question. | Mark the correct option with `isCorrect: true`. |
| `short_answer` | Free-text answer graded against a model answer. | Provide model answer text in `answers[0]`. |
| `long_answer` | Extended free-text answer graded against criteria. | Provide model answer text in `answers[0]`. |

---

## Example

```json
{
  "sectionId": "sec_abc",
  "sectionType": "single_choice",
  "pointsPerQuestion": 5,
  "questions": [
    {
      "questionId": "q_001",
      "questionText": "Which hook manages side effects in React?",
      "marks": 5,
      "answers": [
        { "answerId": "a_1", "answerText": "useEffect", "isCorrect": true },
        { "answerId": "a_2", "answerText": "useState", "isCorrect": false },
        { "answerId": "a_3", "answerText": "useMemo", "isCorrect": false }
      ]
    }
  ]
}
```
