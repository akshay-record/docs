---
title: "Update Assessment"
api: "PUT /api/v1/assessments/{assessmentId}"
description: "Update assessment metadata, builder content, and publish state."
---

## Overview

Use a single `PUT` endpoint to update metadata, knowledge sections, coding problems, and publishing state.

<Note>
  Before publishing, the system validates that the sum of all question marks equals `totalMarks`.
</Note>

---

## Path Parameters

<ParamField path="assessmentId" type="string" required>
  Assessment identifier.
</ParamField>

---

## Request Body

<ParamField body="orgId" type="string" required>
  Organization identifier.
</ParamField>

<ParamField body="sections" type="array">
  Knowledge question sections.
</ParamField>

<ParamField body="codingProblems" type="array">
  Coding problems for IT assessments.
</ParamField>

<ParamField body="isPublished" type="boolean">
  Whether to publish the assessment.
</ParamField>

---

## Response Fields

<ResponseField name="success" type="boolean">
  `true` when the assessment is updated.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="Updated assessment fields">
    <ResponseField name="assessmentId" type="string">
      Updated assessment identifier.
    </ResponseField>
    <ResponseField name="sections" type="array">
      Updated knowledge sections.
    </ResponseField>
    <ResponseField name="codingProblems" type="array">
      Updated coding problems.
    </ResponseField>
    <ResponseField name="isPublished" type="boolean">
      Current publish state.
    </ResponseField>
    <ResponseField name="updatedAt" type="string">
      ISO 8601 update timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

---

<RequestExample>
```bash cURL
curl --request PUT \
  --url https://api.getrecord.in/api/v1/assessments/asmnt_abc123 \
  --header 'Authorization: Bearer your_access_token' \
  --header 'Content-Type: application/json' \
  --data '{
    "orgId": "RORG123456",
    "sections": [],
    "codingProblems": [],
    "isPublished": true
  }'
```
</RequestExample>

<ResponseExample>
```json 200 OK

  "success": true,

    "sections": [],
```
