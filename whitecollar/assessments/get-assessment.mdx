---
title: "Get Assessment"
api: "GET /api/v1/assessments/{assessmentId}"
description: "Retrieve an assessment by ID."
---

## Overview

Retrieves one assessment by ID.

<Note>
  Requires a valid bearer access token. The assessment must belong to the requested organization.
</Note>

---

## Path Parameters

<ParamField path="assessmentId" type="string" required>
  Assessment identifier.
</ParamField>

---

## Query Parameters

<ParamField query="orgId" type="string" required>
  Organization identifier.
</ParamField>

---

## Response Fields

<ResponseField name="success" type="boolean">
  `true` when the assessment is returned.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="Assessment fields">
    <ResponseField name="assessmentId" type="string">
      Unique assessment identifier.
    </ResponseField>
    <ResponseField name="name" type="string">
      Assessment name.
    </ResponseField>
    <ResponseField name="mode" type="string">
      `test` or `live`.
    </ResponseField>
    <ResponseField name="roleType" type="string">
      `IT` or `NON-IT`.
    </ResponseField>
    <ResponseField name="sections" type="array">
      Knowledge sections.
    </ResponseField>
    <ResponseField name="codingProblems" type="array">
      Coding challenges for IT roles.
    </ResponseField>
    <ResponseField name="isPublished" type="boolean">
      Whether the assessment is published.
    </ResponseField>
    <ResponseField name="isActive" type="boolean">
      Whether the assessment accepts candidates.
    </ResponseField>
  </Expandable>
</ResponseField>

---

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.getrecord.in/api/v1/assessments/asmnt_abc123?orgId=RORG123456' \
  --header 'Authorization: Bearer your_access_token'
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "success": true,
  "data": {
    "assessmentId": "asmnt_abc123",
    "name": "Frontend Developer Assessment",
    "mode": "live",
    "roleType": "IT",
    "sections": [],
    "codingProblems": [],
    "isPublished": false,
    "isActive": true
  }
}
```

```json 401 Unauthorized
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Access token missing or invalid."
  }
}
```

```json 403 Forbidden
{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "User does not have permission to read assessments."
  }
}
```

```json 404 Not Found
{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "Assessment does not exist."
  }
}
```
</ResponseExample>
