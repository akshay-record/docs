## Overview

Coding problems are available for `IT` role assessments.

| Field | Type | Description |
| --- | --- | --- |
| `problemId` | `string` | Unique problem identifier. |
| `title` | `string` | Problem title. |
| `marks` | `number` | Marks awarded for the problem. |
| `allowedLanguages` | `string[]` | Languages candidates may use. |
| `problemStatement` | `string` | Full problem description. |
| `sampleInput` | `string` | Visible sample input. |
| `sampleOutput` | `string` | Expected output for the sample input. |
| `solutionLanguage` | `string` | Reference solution language. |
| `solutionCode` | `string` | Reference implementation. |
| `solutionExplanation` | `string` | Approach explanation. |
| `testCases` | `TestCase[]` | Hidden validation test cases. |

---

## Example

```json
{
  "problemId": "prob_001",
  "title": "Find the maximum element",
  "marks": 20,
  "allowedLanguages": ["Python", "JavaScript", "Java"],
  "problemStatement": "Given an array of integers, return the maximum value.",
  "sampleInput": "[3, 1, 4, 1, 5, 9, 2, 6]",
  "sampleOutput": "9",
  "solutionLanguage": "Python",
  "solutionCode": "def solve(arr): return max(arr)",
  "solutionExplanation": "Python's built-in max() runs in O(n).",
  "testCases": [
    {
      "input": "[1,2,3]",
      "expectedOutput": "3",
      "explanation": "Last element is max"
    }
  ]
}
```
