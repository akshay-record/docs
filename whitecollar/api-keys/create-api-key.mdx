---
title: "Create API Key"
api: "POST /api/v1/api-keys"
description: "Create a mode-scoped API key."
---

## Overview

Creates an API key for an organization.

<Note>
  Requires `Content-Type: application/json` and a valid bearer access token. The `secretKey` is returned only once.
</Note>

---

## Query Parameters

<ParamField query="orgId" type="string" required>
  Organization identifier.
</ParamField>

---

## Request Body

<ParamField body="name" type="string" required>
  Human-readable key label.
</ParamField>

<ParamField body="mode" type="string" required>
  Environment scope. Must be `test` or `live`.
</ParamField>

<ParamField body="projectId" type="string">
  Optional project identifier.
</ParamField>

<RequestExample>
```bash cURL
curl --request POST \
  --url 'https://api.getrecord.in/api/v1/api-keys?orgId=RORG123456' \
  --header 'Authorization: Bearer your_access_token' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Production Integration",
    "mode": "test",
    "projectId": "proj_xxx"
  }'
```
</RequestExample>

---

## Response Fields

<ResponseField name="success" type="boolean">
  `true` when the key is created.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="API key fields">
    <ResponseField name="keyId" type="string">
      Unique key identifier.
    </ResponseField>
    <ResponseField name="apiKey" type="string">
      Public API key sent in `x-api-key`.
    </ResponseField>
    <ResponseField name="secretKey" type="string">
      Secret key returned one time only.
    </ResponseField>
    <ResponseField name="mode" type="string">
      `test` or `live`.
    </ResponseField>
    <ResponseField name="name" type="string">
      Human-readable key label.
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>
