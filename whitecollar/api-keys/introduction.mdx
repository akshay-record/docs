## Overview

API keys authenticate external services and integrations with the Record Studio API.

Every key is scoped to a mode. A `test` key cannot be used against `live` endpoints, and a `live` key cannot be used against `test` endpoints.

## Key properties

| Field | Type | Description |
| --- | --- | --- |
| `keyId` | `string` | Unique key identifier, such as `key_test_abc123`. |
| `apiKey` | `string` | Public API key sent in the `x-api-key` header. |
| `secretKey` | `string` | Secret key returned once when you create the key. |
| `mode` | `"test" \| "live"` | Environment scope of the key. |
| `name` | `string` | Human-readable label. |
| `orgId` | `string` | Owning organization identifier. |
| `createdAt` | ISO 8601 date | Timestamp of key creation. |

<Warning>
  The `secretKey` is returned only once. Store it securely in an environment variable. If you lose it, delete the key and create a new one.
</Warning>
