---
title: "List API Keys"
api: "GET /api/v1/api-keys"
description: "Return API keys for an organization."
---

## Overview

Returns all API keys for the organization. The response excludes `secretKey`.

<Note>
  Requires a valid bearer access token. API keys are filtered by organization and mode.
</Note>

---

## Query Parameters

<ParamField query="orgId" type="string" required>
  Organization identifier.
</ParamField>

<ParamField query="mode" type="string" required>
  Filters keys by mode. Must be `test` or `live`.
</ParamField>

---

## Response Fields

<ResponseField name="success" type="boolean">
  `true` when the request succeeds.
</ResponseField>

<ResponseField name="data" type="array">
  API key records. The `secretKey` is never returned.

  <Expandable title="API key fields">
    <ResponseField name="keyId" type="string">
      Unique key identifier.
    </ResponseField>
    <ResponseField name="apiKey" type="string">
      Public API key.
    </ResponseField>
    <ResponseField name="mode" type="string">
      `test` or `live`.
    </ResponseField>
    <ResponseField name="name" type="string">
      Human-readable key label.
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

---

<RequestExample>
```bash cURL
curl --request GET \
```
