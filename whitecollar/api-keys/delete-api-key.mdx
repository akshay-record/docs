---
title: "Delete API Key"
api: "DELETE /api/v1/api-keys/{keyId}"
description: "Delete an API key by key ID."
---

## Overview

Deletes an API key for an organization.

<Note>
  Delete a lost or compromised key, then create a replacement key. Deleted keys cannot be recovered.
</Note>

---

## Path Parameters

<ParamField path="keyId" type="string" required>
  API key identifier.
</ParamField>

---

## Query Parameters

<ParamField query="orgId" type="string" required>
  Organization identifier.
</ParamField>

---

## Response Fields

<ResponseField name="success" type="boolean">
  `true` when the key is deleted.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable result message.
</ResponseField>

---

<RequestExample>
```bash cURL
curl --request DELETE \
  --url 'https://api.getrecord.in/api/v1/api-keys/key_test_4f3a9c?orgId=RORG123456' \
  --header 'Authorization: Bearer your_access_token'
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "success": true,
  "message": "API key deleted successfully"
}
```

```json 401 Unauthorized
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Access token missing or invalid."
  }
}
```

```json 403 Forbidden
{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "User does not have permission to delete API keys."
  }
}
```

```json 404 Not Found
{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "API key does not exist."
  }
}
```
</ResponseExample>
