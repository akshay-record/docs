## 2. Generate Permanent Access Token

To allow Record to send WhatsApp messages through your WhatsApp Business Account, you need to generate a permanent access token.

We recommend creating a dedicated System User and token for Record. This makes access management, auditing, and future maintenance easier.

### Step 1: Open Business Settings

Go to:

```text
business.facebook.com/settings
```

Then navigate to:

```text
Users → System Users
```

Create a new System User for Record, or use an existing System User if already configured.

### Step 2: Assign the App

Select the System User and assign the WhatsApp application.

You can either:

- Create a dedicated Meta application for Record
- Use your existing WhatsApp application

Using a dedicated application is recommended for better separation and easier management.

### Step 3: Generate Token

Click **Generate Token** and select the WhatsApp application.

Choose the required WhatsApp permissions and generate the token with **No Expiration**.

### Step 4: Share Token with Record

Please securely share the following details with the Record team:

- Permanent Access Token
- Phone Number ID
- WhatsApp Business Account ID, if available

## 3. Webhook Configuration

Please configure the Record webhook in your Meta Developer Console.

### Callback URL

The Record team will share the webhook callback URL during onboarding.

```text
<RECORD_CALLBACK_URL>
```

Example:

```text
https://your-domain.com/api/v1/webhooks/whatsapp
```

### Verify Token

The Record team will also share the verify token.

```text
<RECORD_VERIFY_TOKEN>
```

### Webhook Events

Please subscribe to the following webhook events:

- messages
- message\_status
- message\_template\_status\_update

After entering the Callback URL and Verify Token, click **Verify and Save**.

## 4. Meta Developer Configuration Flow

### Step 1: Open Meta Developers

Go to:

```text
developers.facebook.com
```

Sign in using the Meta Business account connected with your WhatsApp Business Account.

### Step 2: Open App Dashboard

Open your Meta application dashboard.

From the dashboard, go to **Use Cases** and select:

```text
Connect with customers through WhatsApp
```

### Step 3: Complete Production Setup

Under the WhatsApp production setup, add the Record backend webhook URL and verify token.

After verification is successful, continue with the remaining WhatsApp setup.

### Step 4: Register WhatsApp Number

Complete the following setup items:

- Register your WhatsApp Business phone number
- Complete business verification, if required
- Add payment method, if required by Meta
- Complete phone number registration

Once completed, your WhatsApp number will be ready for integration with Record.

## 7. Recommended WhatsApp Templates

### Template 1: Job Interest

**Category:** Utility

**Body:**

```text
Hi {{1}},

We have a job opportunity for you.

Are you currently looking for work?

Reply STOP to opt out of future messages.
```

**Buttons:**

```text
Yes, interested
No, not now
```

**Variables:**

| Variable | Description |
| --- | --- |
| `{{1}}` | Candidate Name |

### Template 2: Skill Assessment Invitation

**Category:** Utility

**Body:**

```text
Thanks for confirming!

{{1}} would like you to complete a quick skill check for the {{2}} role.

It takes about 5-10 minutes. Simply answer a few questions in your own words.

Tap here to begin:
{{3}}

Thank you!
```

**Variables:**

| Variable | Description |
| --- | --- |
| `{{1}}` | Company Name |
| `{{2}}` | Job Role |
| `{{3}}` | Assessment URL |

Example URL:

```text
https://verification.userecord.io/verification?id=2357
```

### Template 3: Not Interested

**Category:** Utility

**Body:**

```text
No worries.

Thanks for letting us know.

We'll keep your profile in mind if a suitable opportunity comes up.

Wishing you all the best!

Reply STOP to opt out of future messages.
```

### Template 4: Assessment Completed


**Variables:**

| Variable | Description |
| --- | --- |
| `{{1}}` | Candidate Name |

## 8. Best Practices

To improve message delivery and candidate engagement:

- Keep messages short, clear, and conversational.
- Avoid words like “profile verification” or “employment verification”.
- Avoid long raw URLs in the message body wherever possible.
- Use CTA buttons for links when available.
- Always include opt-out text.
- Use localized language instead of direct word-for-word translation.
- Share the final approved template names with Record after Meta approval.

## 9. Final Details to Share with Record

Once the setup is complete, please share:

- Phone Number ID
- Permanent Access Token
- WhatsApp Business Account ID, if available
- Confirmation that the webhook is verified
- Approved template names for all required languages
- Confirmation that the WhatsApp Business number is registered and ready

After receiving these details, the Record team will complete the configuration and activate WhatsApp messaging.
