---

Install the client SDK via npm, yarn, or a CDN script tag.

### npm / yarn

```bash
npm install @yourplatform/verify-sdk
# or
yarn add @yourplatform/verify-sdk
```

### CDN (browser)

```html
<script src="https://cdn.yourplatform.io/sdk/v1/verify.min.js"></script>
```
