---
title: "Analytics"
description: "Funnel, channel and drop-off numbers for a workflow, job mandate or campaign."
---

The same numbers the Record playground shows on a workflow's Overview: how many invites went out, how many candidates started and finished, which channel they finished on, follow-ups, calls, where people drop off, completion by language and what other work candidates would take. Counts only: no names or phone numbers.

| Needs | You get | Scope |
|---|---|---|
| `workflow_id`, `mandate_id` or `campaign_id` from the steps above | funnel, channels, follow-ups, calls, drop-offs, languages | `analytics:read` |

## What you get

| Section | Contents |
|---|---|
| `assigned_candidates` | Candidates added to the campaigns in scope. |
| `tracked_candidates` | Candidates with a status row in the logs. |
| `funnel` | `sent` (invites sent), `started` (replied interested or started the verification), `not_started` and `completed` (finished with a verdict). |
| `verification_methods` | Completions by `video` (verification link) and `audio` (phone call). |
| `whatsapp` | Messages `sent`, `delivered`, `replied`, `failed`, and completions through WhatsApp. |
| `follow_ups` | Candidates reached by the first message and each follow-up, and `completed_after_follow_up` (completed after at least one nudge). |
| `calls` | Calls `initiated`, `completed`, `not_answered` and `not_interested`. |
| `channel_conversions` | Completions by `whatsapp`, `sms` and `phone_call`. |
| `drop_offs` | Count and percentage for `sent_not_started`, `started_no_verification` and `completed_no_verdict`. |
| `completion_by_language` | `reached`, `completed` and `completion_rate` per language. |
| `other_interests` | How many completed candidates are `open_to_other` roles, the roles they named, and their experience. |

## Endpoints

### Get workflow analytics

`GET /analytics/workflows/{workflow_id}`

The workflow Overview numbers from the Record playground. Add `mandate_id` and/or `campaign_id` to narrow it to one job or campaign; each must belong to this workflow.

**Scope:** `analytics:read`

| Query | Type | Description |
|---|---|---|
| `mandate_id` | `string` | Only this job mandate. |
| `campaign_id` | `string` | Only this campaign. |

<CodeGroup>

```javascript JavaScript
const res = await call("GET", "/api/v1/partner/analytics/workflows/WF_BG_261009101530123K7M2P9Q4X7R5T8");
const { data } = await res.json();
```

```python Python
res = call("GET", "/api/v1/partner/analytics/workflows/WF_BG_261009101530123K7M2P9Q4X7R5T8")
data = res.json()["data"]
```

