title: "Skills"
description: "Step 2a. Find the skills for a job mandate, or ask for a missing one."
---

Every mandate needs skills from Record's skill taxonomy. Store the `skill_id` values your recruiters pick and send them as the mandate's `skills`. These are helper endpoints: the sample mandate already uses real skill ids, so you can skip this and come back when you build your own skill list.

| Need | Endpoint |
|---|---|
| Type-ahead search | `GET /skills/search` |
| Browse the tree | `GET /skills/domains` → `GET /skills/domains/{domain_id}/sub-domains` → `GET /skills/sub-domains/{sub_domain_id}/skills` |
| One skill | `GET /skills/{skill_id}` |
| Re-check stored ids | `POST /skills/lookup` (up to 50) |
| Map free text to skills | `POST /skills/match`. `suggestion` is `auto` (use it), `confirm` (ask the recruiter) or `none`. |
| Suggest from a job description | `POST /skills/extract` |
| Ask for a missing skill | `POST /skill-requests` |

## Missing skills

If search cannot find a skill, ask Record to add it with `POST /skill-requests` and put it on the mandate as `{ "name": "Reach Truck Operation", "pending": true }`. A pending skill is kept on the mandate but cannot be verified until the request is resolved. Track the request with `GET /skill-requests/{request_id}`.

## Usage limits

Search and browse return at most 15,000 different skills per key per day, and more than 200 browse pages in an hour puts the key in cooldown. There is no bulk export: store only the skills your recruiters pick. See [Limits](/blue-collar-api/reference/limits).

## Endpoints

### Search skills

`GET /skills/search`

Type-ahead: find skills by a few letters (e.g. “fork”) and keep the `skill_id` the recruiter picks.

**Scope:** `skills:read`

| Query | Type | Description |
|---|---|---|
| `q` | `string` | 2 to 60 characters; matches the start of words, tolerates small typos. |
| `collar` | `string` | Ranks this collar first; does not hide the others. One of `blue`, `grey`, `white`. |
| `domain_id` | `string` | Only skills in this domain (from `GET /skills/domains`). |
| `sub_domain_id` | `string` | Only skills in this sub-domain. |
| `limit` | `integer` | 1 to 20, default 10. |

<CodeGroup>

```javascript JavaScript
const res = await call("GET", "/api/v1/partner/skills/search?q=forklift&limit=10");
const { data } = await res.json();
```

```python Python
res = call("GET", "/api/v1/partner/skills/search?q=forklift&limit=10")
data = res.json()["data"]
```

```bash cURL
pcall GET "/api/v1/partner/skills/search?q=forklift&limit=10"
```

### Request a skill

`POST /skill-requests`

**Scope:** `skills:request` · **Idempotency-Key:** required

| Field | Type | Description |
|---|---|---|
| `name` | `string` | **Required.** 2 to 120 characters. |
| `collar` | `string` | One of `blue`, `grey`, `white`. |
| `domain_hint` | `string` | At most 200 characters. |
| `mandate_external_id` | `string` | Your own id (1 to 128 of A-Z a-z 0-9 . _ : -). |
