## Objects

| Object | Values |
|---|---|
| Workflow | `active` · `inactive` · `draft` · `archived` |
| Job mandate | `preparing` → `ready` (or `failed`) · `archived` |
| Mandate skill | `active` · `pending` (requested, not resolved yet) · `not_found` (removed from the taxonomy) |
| Campaign | `draft` · `waiting_for_questions` · `blocked` · `sending` · `paused` · `completed` · `cancelled` |
| Skill request | `pending` · `approved` · `merged` · `rejected` · `duplicate_of` |
| Webhook endpoint | `active` · `paused` · `auto_paused` · `disabled` |
| Webhook delivery | `pending` · `in_flight` · `retrying` · `held` · `delivered` · `dead` |

## Candidates

| Field | Values |
|---|---|
| Result `status` | `pending` · `completed` · `declined` · `failed` |
| Result `reason` (failed only) | `undeliverable` · `no_response` |
| Candidate row `status` | `interested` · `not_interested` · `no_answer_yet` · `unreachable` |
| Candidate row `progress` | `not_yet_started` → `in_progress` → `completed` |
| Link `delivery` | `queued` · `sent` · `failed` |
| Rejected candidate `reason` | `invalid_phone` · `duplicate_in_request` · `already_in_campaign` |

## Job settings

| Field | Values |
|---|---|
| Checks (`methods`) | `data_enrichment` (your questions) · `skill_verification` · `interest_collection` |
| Screening question `type` | `yes_no` · `voice` |
| `location_type` | `india` · `abroad` |
| Skill `collar` | `blue` · `grey` · `white` |
| Skill match `suggestion` | `auto` · `confirm` · `none` |
| Campaign `start` | `now` · `manual` |
| Languages | `en` English · `hi` Hindi · `ta` Tamil · `te` Telugu · `kn` Kannada · `ml` Malayalam |
| Schedule `days` | `mon` · `tue` · `wed` · `thu` · `fri` · `sat` · `sun` |
